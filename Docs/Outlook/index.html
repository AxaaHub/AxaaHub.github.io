Outlook 邮箱安全设置教程

从邮箱设置、第三方授权到安全信息、恢复代码与两步验证（可选），逐步检查你的个人 Microsoft 账户

最后更新：2026-11-02

一、开始前的准备

Outlook.com 邮箱使用个人 Microsoft 账户登录。检查邮箱安全时，除了修改密码，还应核对邮件转发、收件规则、应用授权和身份验证方式。本教程将这些设置整理成一条可逐项完成的操作路线，适用于 Outlook.com、Hotmail、Live 等个人账户；工作或学校账户的入口与权限由组织管理，可能不同。

动手前，先准备好：

  • 一台你信任的设备：浏览器与系统保持更新；如果怀疑设备感染恶意软件，先按微软的账户被盗处理流程检查设备，再修改密码。
  • 一个长期由你管理的备用邮箱：先确认能正常登录和收信，避免添加后收不到验证码。
  • 当前可用的登录或验证方式：操作期间可能多次要求验证身份，先确认你能完成验证，再处理旧信息。
  • 保存新密码和恢复代码的位置：提前安排好，避免生成后遗漏保存。
下文提供 6 张高清配图，点击可查看完整尺寸。配图用于定位设置入口，微软可能调整菜单名称、位置和可用选项，请以你账户实际显示为准。

二、登录账户

直达入口：Microsoft 账户登录

1
打开登录页，输入本次要检查的 Outlook 邮箱地址，点击下一步 / Next。如果浏览器已经登录了其他 Microsoft 账户，先切换到账户对应的会话；也可以用无痕窗口避免混淆。

输入需要登录的邮箱地址。点击图片查看高清原图。

验证码与验证提示

2
按照账户提供的方式登录。如果页面显示通过电子邮件发送代码 / Email a code，按提示补全已绑定的备用邮箱地址，再点击发送代码 / Send code；如果没有此选项，使用页面实际提供且由你掌握的密码、验证应用或其他登录方式。
3
到对应备用邮箱收取验证码，返回当前窗口完成验证。打开备用邮箱时，使用另一个窗口或浏览器会话，避免把正在验证的账户切换掉。

备用邮箱验证码验证界面。图片中的邮箱为占位示例。

验证码登录不代表后续操作一定不会再触发身份验证。微软可能根据设备、位置和操作要求额外验证；频繁重复请求验证码还可能受到限制。遇到收不到代码或验证受限时，参考验证码问题排查说明，不要连续重试。

若询问是否保持登录，在自己的可信设备上按需要选择；公共或共享设备不要保持登录，使用结束后主动退出并关闭会话。参见微软的账户安全建议。

能够进入目标账户，并且清楚当前使用的是哪个账户、哪一种身份验证方式。

三、检查邮箱设置

直达入口：Outlook 网页邮箱

打开邮箱右上角的设置齿轮，进入邮件 / Mail。这里要分别检查自动转发、收件规则和 POP / IMAP；它们是不同的设置项。

1. 检查自动转发

  1. 找到转发 / Forwarding，部分界面显示为转发和 IMAP / Forwarding and IMAP。
  2. 检查是否启用了转发，以及目标邮箱地址是否属于你、是否仍有用途。
  3. 对不认识或不需要的自动转发，关闭启用转发 / Enable forwarding，并保存设置。

操作参考：在 Outlook.com 中打开或关闭自动转发。

自动转发与 POP / IMAP 设置。截图中的红框分别标出了需要核对的开关。

2. 补查收件规则

在设置 → 邮件 → 规则 / Rules中逐条查看规则的条件和动作。重点检查会把邮件转发、重定向到陌生地址，或把重要邮件删除、移动到其他文件夹的规则；确认不是自己需要的规则后，再停用或删除。

关闭自动转发开关后，仍要检查规则。规则本身也能把邮件转发或重定向到其他地址，不能只看上一节的转发开关。参见使用规则自动转发邮件。

3. 按实际需要关闭 POP / IMAP

如果你只使用网页邮箱，不需要通过 POP 或 IMAP 收取邮件，可将允许设备和应用使用 POP / IMAP关闭并保存。如果正在使用 Thunderbird 等邮件客户端，先确认它的连接方式与用途，关闭后相应客户端可能无法继续同步邮件。

微软目前说明 Outlook.com 的 POP / IMAP 访问默认关闭，需要使用时才手动开启，并采用 OAuth2 / Modern Auth。菜单位置以官方 POP、IMAP 和 SMTP 设置说明为准。

没有陌生的转发目标或收件规则；POP / IMAP 的启用状态符合你实际使用的邮件客户端需求。

四、清理第三方授权

直达入口：你已授予访问权限的应用和服务

这里管理的是应用授权。某些邮件客户端或服务获准后，可以在相应权限范围内访问邮件或账户数据，因此要核对应用名称与权限，不能仅把它理解为设备登录记录。

1
打开授权列表，逐项确认应用是否由你添加、现在是否仍在使用；点进应用查看其获得的权限。
2
对于陌生或已经不再使用的应用，进入详情，选择删除这些权限 / Remove these permissions，按提示撤销授权。需要保留的客户端先确认用途，避免误删后影响日常收信。

列表为空时的示例；如果已有授权，这里会显示相应应用。微软在应用授权撤销说明中也使用此授权管理入口。

列表为空只说明这个授权列表中没有应用，仍需继续核对安全验证方式和近期活动。

授权列表中只保留你认识且确实需要的应用与权限。

五、更新安全信息

直达入口：管理登录和身份验证方式

安全信息用于接收验证码、验证身份或帮助恢复账户。这里的备用邮箱与邮箱别名、邮件转发目标是不同设置；本章处理的是安全验证方式。

1. 先添加并验证自己的方式

  1. 找到添加新的登录或验证方式 / Add a new way to sign in or verify。
  2. 选择页面提供的邮箱验证等方式，填写长期由你管理的备用邮箱。
  3. 到新邮箱收取验证码，返回完成验证，确认新方式已出现在安全信息列表中。

登录与身份验证方式列表。当前可添加的选项可能不同，部分账户可能不再提供添加手机号的选项。参见Microsoft 账户安全信息与验证码。

2. 检查并移除旧方式

新方式验证完成后，再逐项核对旧的备用邮箱、手机号、验证应用、通行密钥等登录或验证方式。对于不属于你、已经无法使用或不再需要的项目，展开对应条目，按页面提示移除；仍由你使用的方式可以保留。

不要先删光再添加。开始移除前，确认新的验证方式可用，并始终保留自己掌握的有效方式。如果旧方式全都无法使用，应按账户恢复提示处理，不能把“我没有这些信息”当作普通换绑的捷径。具体处理方式参见安全信息丢失与验证码排查说明。

3. 留意 30 天等待期

微软说明，移除并替换全部安全信息可能使账户进入30 天的受限等待期，部分需要安全验证的操作暂时不可用。普通添加一个新备用邮箱与替换全部安全信息不是同一种流程。

如果看到安全信息更改仍在等待中 / Security info change is still pending，先阅读页面所列限制和生效时间，不要反复提交替换请求；若该变更并非你本人发起，使用页面的“让我们知道”等入口报告。详见安全信息更改等待期说明。

已验证至少一种自己掌握的有效方式，列表中没有陌生验证方式，并清楚是否存在待生效的安全信息变更。

六、修改密码

直达入口：更改 Microsoft 账户密码

1
打开更改密码页面，确认账户无误，并按提示完成身份验证。若直达链接只打开账户首页，进入安全 → 更改密码。
2
按页面要求输入当前密码及新密码。新密码使用足够长且不与其他网站重复的内容；可以使用密码管理器生成并保存。
3
提交保存，确认页面提示更改成功，并更新自己保存的密码记录。随后继续处理恢复代码和其他登录会话。
Outlook.com 密码就是该 Microsoft 账户的密码，修改后会影响使用同一账户登录的其他 Microsoft 服务。如果忘记当前密码，应走“忘记密码”的恢复流程；无密码账户按其现有登录方式和安全页面提示管理，不必为了照抄本章额外添加密码。参见更改 Outlook.com 密码和账户安全说明。

更改密码成功，新密码已妥善保存；若是无密码账户，已确认现有登录方式均由自己掌握。

七、恢复代码与退出登录

直达入口：高级安全选项，与第五章管理安全信息使用同一入口。

1. 生成并保存恢复代码

  1. 找到恢复代码 / Recovery code。
  2. 点击生成新代码 / Generate a new code，按提示完成验证。
  3. 立即保存新生成的 25 位恢复代码。微软建议打印后放在安全位置，并避免存放在用于登录该账户的设备上。
生成新恢复代码后，旧代码立即失效。已有代码不能事后从账户中重新查看；若没有保存，只能在仍可登录时再生成一份，并以最新一份为准。参见微软恢复代码说明。

恢复代码与邮件中的一次性验证码用途不同，请单独保管。不要把它发给别人，也不要只存在这个 Outlook 邮箱里，以免无法登录时同时失去取回代码的途径。

2. 退出其他会话

  1. 在同一安全页面找到退出所有登录 / Sign out everywhere。
  2. 确认密码、验证方式和恢复代码已经处理妥当后，选择退出，并按页面提示完成操作。
  3. 重新登录自己需要使用的浏览器或应用，再检查近期活动。

红色数字 1 对应生成恢复代码，数字 2 对应退出登录。

退出可能需要最多 24 小时，并且不包含 Xbox 主机。不要把点击成功理解为所有设备立即退出。此操作处理的是登录会话，仍应分别检查应用授权和邮箱转发。时间与例外以微软退出所有登录说明为准。

最新恢复代码已保存，退出操作已提交；已了解它的生效时间和 Xbox 例外。

八、开启两步验证（可选）

直达入口：Microsoft 账户安全页面 → 管理登录方式 / Manage how I sign in

两步验证为账户增加一层身份核验。本章为可选步骤，可按需决定是否开启。启用前，先确保验证方式、备用邮箱和恢复代码都由自己掌握，以免更换手机或无法收信时被锁在账户外。

1. 配置两步验证

  1. 在账户安全页面打开管理登录方式，找到其他安全设置 / Additional security。
  2. 在两步验证 / Two-step verification下选择开启 / Turn on。
  3. 按页面提示配置验证方式，并完成一次验证。需要扫描二维码时，使用自己掌握的验证设备。
  4. 返回安全页面，确认两步验证状态为已开启。
Microsoft Authenticator 是微软支持的验证方式之一，也可按账户页面提供的选项配置其他方式。选择时应考虑设备更换、丢失后的恢复途径，并确认备用验证方式可用。操作依据：Microsoft 账户两步验证说明。

2. 准备备用验证途径

  • 保留多种仍可使用、由自己掌握的验证方式，不要把所有方式都集中在同一台可能丢失的手机上。
  • 确认备用邮箱本身能够登录，且没有使用与此账户相同的密码。
  • 按第七章保管恢复代码；如果设置过程中重新生成了代码，以最新保存的一份为准。
  • 更换手机前，先确认新设备上的验证方式可用，再处理旧设备。
开启两步验证后，丢失验证方式可能导致长时间无法恢复访问。微软建议关联三项安全信息以备不时之需；可用方式以当前账户页面为准，不要求一定添加手机号。

如选择开启，确认两步验证已启用、常用与备用验证方式均可使用，且恢复代码有独立的保存位置；如不启用，可跳过本章，继续下一章的检查。

常见问题

为什么我看到的菜单与截图不同？

配图用于说明设置入口，微软可能调整页面布局和可用选项。优先根据正文中的功能名称查找；直达链接未进入目标页时，从账户安全页面或 Outlook 设置继续操作。

没有验证码登录选项，是否必须换一种方式？

不必强求。使用账户当前提供且由你掌握的方式，额外验证按提示完成；登录方式不会保证免除后续验证。收不到代码时查看官方排查说明。

提示安全信息更改还要等待 30 天怎么办？

先核对变更是否本人发起、何时生效和当前受限项目。不是本人发起的变更，按页面指引报告；本人发起的替换按微软给出的流程处理。不要把普通添加备用邮箱与替换全部安全信息混为一谈。
