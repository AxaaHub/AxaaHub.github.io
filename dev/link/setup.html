一、启动工具

需要 Node.js 22 或更高版本。首次在新设备使用时安装依赖和独立 Chromium：

cd "$HOME/Desktop/MyRepository/AxaaHub.github.io/dev/link/server"
npm ci
npm run install:browser

启动：

cd "$HOME/Desktop/MyRepository/AxaaHub.github.io/dev/link/server"
npm start

保持终端运行，在浏览器打开 http://127.0.0.1:8787/。按 Ctrl + C 停止服务。服务默认只监听本机回环地址，同时提供页面和 API，无需另开静态文件服务器。

请通过 HTTP 页面使用工具。单独双击 index.html 并不能启动检测服务，file:// 下的模块加载与本地存储也不能代替正常网站运行环境。

二、检查与最近查询

  1. 输入包含 http:// 或 https:// 的完整网址，选择检测方式和访问设备。
  2. 点击“开始检查”，实时查看已观察到的地址；运行中可“停止检查”。
  3. 查看实际终点与结束原因。参数中声明的 ReturnUrl 等目标会单列，并标记是否实际收到过响应。
  4. 逐条复制完整地址，或导出 JSON / 文本。网址参数及编码会保留。

最近查询

默认保存最近 20 条摘要到当前浏览器的 localStorage。相同完整网址、模式与设备组合更新到最前。点击条目只回填，点击“重查”才联网。关闭“记录查询”后停止新增，已有记录仍可删除；清空全部需要确认。

历史键为 axaahub.link.recent.v1。仅保存查询配置、时间、结束状态、地址数量与最终地址，完整链路请使用导出。清空操作只影响本工具历史，主题偏好及其他工具的数据保留。

记录不额外上传或跨设备同步；执行检查的网址仍会发送给所连接的后端。不同端口和域名具有独立记录。浏览器拒绝存储或记录损坏时会提示，但仍可检查链接。

生成二维码

点击页面顶部“生成二维码”，在弹窗输入网址、中文或多行文本，然后点击“生成二维码”预览；可下载高清 PNG。内容修改后旧图会收起，需要重新生成。

二维码在当前浏览器本地生成，不调用外部二维码接口，也不写入最近查询。输入内容按原样编码，保留空格、换行与网址参数；超过二维码容量时会提示缩短。

三、检测边界

模式行为结束含义
快速检查GET 逐跳检查 HTTP 重定向，解析相对 Location，保留本次会话 Cookie。HTTP 链路结束不等于页面不会执行脚本继续跳转。
浏览器检查在独立未登录 Chromium 中观察主页面导航，包括 HTTP、脚本与刷新跳转。子资源不计为跳转步骤。最多观察 30 秒；正常结果也只覆盖该窗口，不能保证更晚没有跳转。

两种模式最多记录 20 个地址。遇登录、验证码、站点频控或访问限制、循环、下载、新窗口、交互提示、非 HTTP 协议、失败或用户停止时保留已有记录。登录与验证码识别使用网址和页面特征，可能有漏判或误判。

仅连接标准端口 80 / 443；拒绝带用户名、密码的网址。浏览器模式只允许 GET / HEAD 网络请求，阻止其他方法；不执行登录、提交表单或点击操作。页面依赖其他请求方法时可能无法完成跳转。

网络隔离与资源限制

每次 DNS 解析拒绝任何包含私网、回环、链路本地、保留地址的答案。快速模式连接到已验证 IP；浏览器的 HTTP 连接与 HTTPS CONNECT 隧道均通过本机受控代理重新验证并固定目标 IP，覆盖重定向和子资源。Chromium 启用沙箱、阻止 Service Worker，并禁用 QUIC 与非代理 WebRTC UDP。

默认全局并发 2、每个来源 IP 每分钟最多 6 次且同时只运行 1 次；每次浏览器检查最多 250 个初始资源请求。HTTP 响应、隧道传输与单次时长另有限制。这里的检查保护不能代替将来公开服务器的系统进程、内存与网络隔离。

四、服务配置

环境变量默认值用途
HOST127.0.0.1监听地址。本轮保持仅本机使用。
PORT8787页面和 API 端口。
MAX_CONCURRENT2全局检测并发，允许 1–8。
RATE_LIMIT6每 IP 每分钟查询次数，允许 1–120。
ALLOWED_ORIGINS空额外允许的前端来源，逗号分隔完整 origin；同源始终允许。
ALLOWED_HOSTSlocalhost,127.0.0.1,[::1]允许访问服务的 Host 主机名，防止任意域名重新绑定到本机。
DNS_SERVERS1.1.1.1,8.8.8.8用于查询实际 A / AAAA 记录的 DNS 服务器 IP，逗号分隔；避免系统 Fake-IP 地址进入检测连接。
API_TOKEN空可选 Bearer 访问口令；仅写后端环境，不能提交到仓库。

DNS 查询默认发送给上述公共解析器；可通过 DNS_SERVERS 改为自己信任的解析器。无论解析来源如何，所有返回地址仍须通过公网地址检查，连接时固定已验证 IP，不允许把 Fake-IP 测试网段加入放行列表。

公开配置 config.js 的 apiBase 用于指定后端根地址；留空时本地页面自动使用同源地址。也可在工具“连接设置”中填写。服务地址保存在浏览器；访问口令只保留在当前页面内存中。

接口：POST /api/trace，JSON 请求：

{"url":"https://example.com/","mode":"browser","profile":"desktop"}

响应为 NDJSON 流，依次发送 started、progress、result。取消客户端请求会终止后端会话；最终结果包含 hops、final、declaredTargets、termination、durationMs、isPartial。健康检查为 GET /api/health。

限流基于实际 TCP 来源地址，故意不信任客户端提供的 X-Forwarded-For。将来接反向代理时，该地址可能变成代理 IP；需在部署方案中设置可信入口和边缘限流，不能直接信任任意转发头。CORS 允许列表不等于接口认证。

五、验证与后续部署

自动检查：

cd "$HOME/Desktop/MyRepository/AxaaHub.github.io/dev/link/server"
npm test

测试使用可控 HTTP 页面和受限的测试传输，不访问第三方站点。覆盖 HTTP / Cookie / 相对跳转、脚本与刷新导航、真实终点与参数目标分离、内网及 DNS 重绑定拦截、取消、循环、最近查询和接口限流。测试专用 test/preview.mjs 使用 8788 端口与隔离数据，仅供开发验收，生产入口不会导入它。

本轮交付为本地可运行版本。后端部署位置待定，尚未发布到 GitHub Pages，也未创建公网 API。后续部署前端到 /dev/link/，后端单独运行并提供 HTTPS，再配置来源、Host 白名单、系统资源限制和可信入口限流。

参考：Playwright 网络代理、Chromium 启动与沙箱、CDP 导航事件、浏览器本地存储。
